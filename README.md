# 🎓 UniCross 115：跨校系智慧查榜系統
**UniCross 115** 是一款專為 115 學年度大學申請入學設計的高質感 Web 查榜平台。我們將「普通大學」與「科技校院」的繁瑣名單進行深度整合，轉化為直覺、流暢且具備強大分析功能的網頁互動介面。

👉 **[立即進入 115 智慧查榜中心](https://potatosserver.github.io/UniCross-115/)**

---

## 🌟 核心網頁特色

### 🔍 雙維度智慧查詢
- **個人全榜搜尋**：輸入姓名或 8 位應試號碼，系統瞬間橫跨「大學」與「科大」兩大資料庫，列出所有通過篩選的校系。
- **姓名自動關連**：獨家技術處理，讓原本不公開姓名的普大榜單也能與考生姓名（遮罩格式）自動對齊。

### 🧪 進階反向推查 (志願交集分析)
- **多組志願疊加**：支援同時輸入最多 12 組校系志願，精確找出同時錄取這些目標的「潛在競爭對手」。
- **代碼快搜對應**：直接輸入 6 位校系代碼（如 `001012`），系統自動秒速填入對應的學校與系組名稱。
- **全台範圍搜尋**：除了可限定特定考場，更支援「🌏 不限定考場（全台搜尋）」，讓您掌握全台灣的錄取數據交集。

### 🎨 頂級視覺化介面
- **卡片式資訊卡**：查詢結果以精緻的方框呈現，包含號碼、姓名、以及精確的「考場全銜」（如：臺北市立建國高中）。
- **數據統計小卡**：點擊校系可彈出視覺化視窗，清晰顯示「校系代碼」、「招生名額」以及「目前通過篩選人數」。
- **動態回應式設計**：完美適配手機與電腦螢幕，隨時隨地都能輕鬆查榜。

---

## 📂 檔案架構

- `index.html`: **智慧互動中心**。系統的靈魂核心，包含所有搜尋邏輯、反向推查引擎與 UI 介面。
- `exam_local_db.json`: **標準化大數據庫**。存儲普大與科大的完整名額、日期、代碼及錄取清單。
- `cross.py`: **資料供給引擎**。負責定期向官網同步數據並清理格式，供網頁端調用。

---

## 🛠️ 網頁操作指南

1. **一般查詢**：
   - 在搜尋框輸入「考生姓名」或「8位號碼」。
   - 按下 `Enter` 或查詢鍵，下方即刻呈現該生所有錄取紀錄卡。

2. **反向推查模式**：
   - 切換至「反向推查」分頁。
   - **設定範圍**：選擇特定考場或選擇「不限定考場」。
   - **設定志願**：輸入 6 位代碼（系統自動帶出校系）或手動選擇校系。
   - **分析結果**：系統會列出在該範圍內，同時錄取您所設定的所有志願之考生名單。

## 🚀 部署與開發

本系統 frontend 採用純原生開發，無需複雜環境：
- **技術棧**: JavaScript (ES6+), CSS3 (Flexbox/Grid), HTML5.
- **資料處理**: 透過純客戶端 JS 處理萬級數據過濾，保證極速反應。

若要更換數據源，請修改 `index.html` 中的 `GITHUB_URL` 指向您最新的 `exam_local_db.json` 路徑。
